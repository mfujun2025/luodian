站点定位

罗店.cn（中文域名，punycode：xn--4kq07d.cn）是上海宝山区罗店镇的本地信息门户，聚焦四大板块：

  • 景点游玩：罗店古镇、美兰湖的攻略与路线；
  • 本地商家：罗店实体商家免费黄页；
  • 厂房租赁：工业园区厂房、商铺信息展示；
  • 便民服务：政务电话与办事指引。

技术说明

  • 纯静态 HTML / CSS / JavaScript 站点，无后端、无数据库；
  • 托管于 GitHub Pages，通过 DNS 将 罗店.cn 绑定到站点；
  • 表单、评论等动态能力由第三方服务承接，本站不存储用户数据。

站点阶段

  • 当前（未备案阶段）：仅提供免费信息展示与免费商家收录，不开展任何付费经营性业务；
